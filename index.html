화면 수정사항이 반영 안 되시나요?

홈 화면 바로가기는 사파리 캐시가 남을 수 있습니다. 강제 새로고침을 누르면 최신 코드를 즉시 다운로드합니다.

아이폰에서 주소가 안 열릴 때 2가지만 확인해 주세요:

  • Wi-Fi 연결: 아이폰이 LTE/5G 데이터가 아닌, 맥북과 같은 Wi-Fi에 연결되어 있어야 합니다.
  • swdjsj 주소 바로 쓰는 법: 맥북 [시스템 설정] ➔ [일반] ➔ [공유] ➔ 맨 밑 [로컬 호스트 이름]을 swdjsj 로 변경해 주시면 즉시 접속됩니다!
꿀팁: 아이폰 홈 화면에 '가계부 앱'으로 등록하기
  1. 1 아이폰 Safari 브라우저로 위 링크에 접속합니다.
  2. 2 하단 바 중앙의 공유 버튼 (네모 위 화살표 ⎋)을 누릅니다.
  3. 3 메뉴 목록에서 [홈 화면에 추가 ➕]를 선택하고 우측 상단 [추가]를 누릅니다.
  4. 4 홈 화면에 예쁜 앱 아이콘이 생성되며, 주소창 없이 진짜 앱처럼 전체화면으로 실행됩니다!
